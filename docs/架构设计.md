## 0. 架构决策记录（ADR）

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 3D 渲染 | **命令式 three.js**（不引入 R3F） | 场景需要精细控制 GeoJSON 挤出、Raycaster、相机 lerp；原型 code.html 已是命令式，延续一致 |
| UI 层 | React + TS（strict）+ 纯 three.js canvas，HUD 用 HTML 绝对定位浮层 | 3D 与 UI 解耦，文字/卡片不用 3D 文字 |
| 状态 | Zustand（拆 4 个 store） | 轻量、可订阅、便于 scene 与 UI 双向解耦 |
| 数据访问 | **Repository 抽象** + Tauri Rust commands | UI/store 不直接碰文件/网络，日后可换存储/加 mock |
| 存储 | 本地 JSON/GeoJSON（app data 目录）+ localStorage 收藏缓存 | 可手动编辑、可版本控制、可整体复制备份 |
| 天气 | Rust `reqwest` 转发 Open-Meteo + 本地缓存 | 规避 CORS、统一超时重试、断网降级 |
| 投影 | 经纬度 → 局部平面（等距圆柱 + 按当前视域归一化） | 板块不发散，单城市尺度误差可忽略 |
| 离线 | 三端依赖全部 npm 本地化，字体/图片本地 | 满足断网 + 冷启动 ≤3s |

│  场景层（three.js，命令式）                           │
│    SceneManager · builders · camera · picking        │
├────────────────────────────────────────────────────┤
│  数据层（TypeScript，Domain 类型 + Repository 接口）    │

├────────────────────────────────────────────────────┤
│  适配层（Tauri invoke / 桥接）                         │
│    tauriRepository（唯一实现，调用 Rust command）      │
├────────────────────────────────────────────────────┤

依赖方向单向向下：**UI → store → scene/repository → Tauri → Rust**。scene 与 repository 同层，互不依赖，均被 store 编排。

## 3. 领域类型（`data/types.ts`）

与 JSON schema 严格对齐；所有字段必填或显式 `?`，编号用 `string`（行政区划代码/自增 id 统一）。

```ts
export type Province = '江苏省' | '上海市' | '浙江省' | '安徽省';

export interface City {
  id: string;
  name: string;
  province: Province;
  districts: string[];          // district 的 id 列表
  intro?: string;
  featuredDistricts?: string[];
  indexed?: boolean;            // false = 未录入低饱和
}

export interface PersonNote { name: string; note: string }

export interface Food {
  name: string;
  category: string;
  recommend: string;
  note: string;
}

export interface District {
  id: string;
  name: string;
  city: string;
  province: Province;
  oneLiner: string;
  tags: Tag[];
  history?: string;
  culture?: string;
  people?: PersonNote[];
  features?: string[];
  foods?: Food[];
  spots: string[];              // spot 的 id 列表
  cover?: string;
  source?: string;
  updatedAt: string;            // ISO 日期
}

export interface Spot {
  id: string;
  name: string;
  districtId: string;
  lng: number;
  lat: number;
  summary: string;
  image?: string;
  tags: Tag[];
  hot?: boolean;
  suitableFor?: string[];
  duration?: string;
  source?: string;
  updatedAt: string;
}

export type Tag =
  | '古镇' | '山水' | '博物馆' | '寺庙'
  | '亲子' | '拍照' | '徒步' | '历史文化';

// 天气
export interface DailyWeather {
  date: string;                 // 'YYYY-MM-DD'
  code: number;                 // WMO 天气码
  tMax: number;                 // 摄氏度
  tMin: number;
  precip: number;               // 降水概率 %
  windKmh: number;
}
export interface WeatherCache {
  districtId: string;
  fetchedAt: string;            // ISO 时间
  source: 'open-meteo';
  tz: string;
  daily: DailyWeather[];
}

// 收藏
export interface Favorites {
  districts: string[];
  spots: string[];
}

// GeoJSON（最小子集，只用到边界）
export interface GeoFeature {
  id: string;
  name: string;
  geometry: { type: 'Polygon' | 'MultiPolygon'; coordinates: number[][][] | number[][][][] };
}

// 投影结果
export interface ProjectedShape {
  id: string;
  outline: [number, number][];  // 平面二维闭合环
  centroid: [number, number];
}
```

### 4.2 实现与测试

- `tauriRepository.ts`：`import { invoke } from '@tauri-apps/api/core'`，把上述方法映射到 Rust command。
- 预留 `mockRepository.ts`（浏览器无 Tauri 环境 debug 用），实现同一接口，注入本地静态 JSON。

### 4.3 投影（`data/projection.ts`）

```ts
// 等距圆柱近似：本地平面坐标，后续可整体归一化到世界包围盒
export function projectLngLat(lng: number, lat: number, origin: [number, number]): [number, number] {
  const k = 111_320;                    // 米/度 近似
  const x = (lng - origin[0]) * k * Math.cos((origin[1] * Math.PI) / 180);
  const y = (lat - origin[1]) * k;
  return [x, y];
}

export function projectFeature(f: GeoFeature, origin: [number, number]): ProjectedShape[];
```

- `origin` 取当前「城市/区域」的中心点，保证局部尺度误差可忽略。
- MultiPolygon 拆为多个 `ProjectedShape`（三沙/跨水域等行政边界会用到）。
- 板块高度：默认城市按 `h` 映射，区县更低；激活态抬高 + `--board-selected` 高亮。

## 5. 场景层（`scene/`）

### 5.1 SceneManager

命令式单例，负责 WebGL 生命周期：

```ts
export class SceneManager {
  mount(container: HTMLElement): void;
  dispose(): void;
  setCityPlates(shapes: ProjectedShape[]): void;
  setDistrictPlates(shapes: ProjectedShape[], activeId?: string): void;
  setPins(pins: PinData[], activeDistrictId: string): void;
  flyTo(target: CameraTarget): void;     // lerp 下钻
  raycast(x: number, y: number): PickResult | null;
  private tick(): void;                  // requestAnimationFrame
}
```

- renderer：`antialias`、`ACESFilmicToneMapping`、soft shadow。
- 相机：`PerspectiveCamera(46°, aspect, 1, 3500)`，默认 48° 俯仰。
- 每次数据变更采用「重建几何」而非增量 patch，几何量级小（≤ 40 板块 + pin），开销可忽略。

### 5.2 builders / camera / picking / effects

| 模块 | 职责 |
| --- | --- |
| `plates.ts` | `ExtrudeGeometry(shp, { depth, bevel })` + `MeshStandardMaterial` + `EdgesGeometry` 发光线；未录入 `indexed=false` 用灰面无发光 |
| `pins.ts` | 亮点球 + 脉冲环，`userData.spotId`；扩大 Raycaster 击中热区（invisible 大圆盘） |
| `camera.ts` | 极角/方位角钳制、`flyTo` 用 `cubic-bezier(.25,.8,.35,1)` 0.5–0.8s lerp |
| `picking.ts` | `Raycaster` + `setFromCamera`，返回 `{ kind: 'plate' | 'pin', id }` |
| `effects.ts` | `GridHelper`、雷达环、雾 `FogExp2`、粒子（AdditiveBlending） |

## 8. Tauri / Rust 后端

### 8.1 Command 清单

| Command | 签名（Rust） | 说明 |
| --- | --- | --- |
| `list_cities` | `() -> Vec<City>` | 读 `content/cities.json` |
| `get_city` | `(id) -> City` | 单条 |
| `list_districts` | `(city_id) -> Vec<District>` | 读并过滤 |
| `get_district` | `(id) -> District` | 单条 |
| `list_spots` | `(district_id) -> Vec<Spot>` | 读 `content/spots.json` 过滤 |
| `list_city_geo` | `() -> Vec<GeoFeature>` | 读 `geo/cities.geojson` |
| `list_district_geo` | `(city_id) -> Vec<GeoFeature>` | 读对应区县 GeoJSON |
| `load_favorites` / `save_favorites` | `(Favorites)` | 读写 `favorites.json` |
| `export_data` | `() -> String` | 全量序列化，写/返回 |
| `fetch_weather` | `(district_id, lat, lng) -> WeatherCache` | reqwest + 写缓存 |
| `get_cached_weather` | `(district_id) -> Option<WeatherCache>` | 读缓存 |

### 8.2 关键实现点

- `storage.rs`：`app_data_dir()/data/...` 路径解析；读写统一走 `serde_json`；写文件用「临时文件 + rename」保证原子性，防崩溃损坏。
- `weather.rs`：`reqwest::Client` 超时 8s；请求参数拼 `daily=weathercode,temperature_2m_max,temperature_2m_min,precipitation_probability_max,windspeed_10m_max&timezone=Asia/Shanghai`；成功后写 `cache/weather/{id}.json`，失败返回缓存或空。
- `error.rs`：`thiserror` 统一错误，command 返回 `Result<T, String>`（前端统一兜底提示）。

## 9. 关键时序

### 9.1 冷启动

```
bootstrap → data.loadAll() → repository.listCities/listCityGeo
   → projection.projectFeature → SceneManager.setCityPlates
   → navigation 进入 'region'，HUD 渲染 → 可交互（≤ 3s）
```

### 9.2 下钻城市

```
点击城市 plate → navigation.drillIntoCity(id)
   → data.loadDistricts + listDistrictGeo → projection
   → SceneManager.setDistrictPlates → camera.flyTo(city 中心)
   → level='city'，LeftIndex 切到区县列表
```

### 9.3 选区县 + 天气

```
点击区县 plate → navigation.selectDistrict(id) → ui.drawerOpen=true
   → weather.ensureWeather(district)：
        命中缓存 → status='online'（展示）
        未命中 → repository.fetchWeather → 成功后缓存 + 'online'
        断网且无缓存 → status='offline' 占位
```

### 9.4 搜索定位

```
搜索输入 → Fuse 检索（cities+districts+spots 预建索引）
   → 选结果 focusOn(hit)：
        city    → drillIntoCity + flyTo
        district→ selectDistrict + flyTo + 开抽屉
        spot    → 定位到所属区县 → activeDistrict 高亮对应 pin → 弹 SpotCard
```

- 字体：Space Grotesk / Inter / JetBrains Mono 放 `public/assets/fonts`，`@font-face` 本地引用。
- Tailwind CDN 仅存在于原型 code.html；落地改为构建期 Tailwind 或纯 CSS 变量（推荐后者，减少抽象）。

## 11. 落地顺序（M0 边界）

M0 目标「本地能渲染一个城市的区县板块」，只做最小闭环：

1. Tauri 2 + Vite + React + TS 脚手架，three 本地依赖
2. `types.ts` + `repository.ts` + `tauriRepository.ts`（先只用 `listCityGeo` / `listDistrictGeo`）
3. `projection.ts` + `plates.ts`，一个城市真实 GeoJSON 挤出渲染
4. `SceneManager` + `camera`（默认 48° 视点）+ 基础雾/网格
5. `stores/data.ts` + `Shell.tsx` 打通「加载 → 投影 → 渲染」

M0 之外（左索引/抽屉/搜索/天气/收藏）按里程碑 M1–M4 递进迭代。

## 12. 待你确认的两处可替换点

1. **three.js 命令式 vs R3F**：本方案按命令式（延续 code.html）。若更想用 React 组件化声明式管理 3D，可换 `@react-three/fiber`，但 GeoJSON 挤出/拾取/相机 lerp 的精细控制会变绕。
2. **样式：纯 CSS 变量 vs Tailwind**：推荐纯 CSS 变量 + token（代码更薄、不引入构建链）；若偏好 Tailwind 开发效率也可换，两者不冲突。
